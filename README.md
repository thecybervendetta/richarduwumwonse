# Richard Uwumwonse - COS 106 Portfolio

Plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.

## Pages

- index.html - Home: biography, at-a-glance facts, selected work
- about.html - About: education, first-semester transcript results, skills, hobbies, Griffin-SOC walkthrough
- projects.html - Projects: Griffin-SOC (video walkthrough + GitHub), Scope-Safe Recon Engine, Automated Exploit Chain, Academic Planner
- planner.html - Academic Planner: add, complete and delete tasks, saved in your browser
- contact.html - Contact: form with JavaScript validation on every field

## Structure

- css/style.css - single external stylesheet used by every page
- js/main.js - navigation menu, footer year, scroll reveal
- js/planner.js - academic planner (tasks stored in browser localStorage)
- js/contact.js - contact form field validation
- images/ - portrait and illustrative project screenshots
